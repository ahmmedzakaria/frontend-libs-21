# NexaCore Shared

Reusable Angular UI component library shared by NexaCore frontend
applications — form controls, list/data composites (`DataTable`, `FilterBar`,
`SearchToolbar`, `Pagination`, `ExportButton`), workflow composites
(`Wizard`, `WizardStep`, `Stepper`, `ApprovalActions`, `ActivityFeed`),
feedback primitives (`Pill`, `StatusBadge`, `EmptyState`, `Modal`,
`ConfirmDialog`), image preview, and validation UI. Depends on
`@nexacore/platform` for `IconComponent`/the icon registry only. See
`CHANGELOG.md` for the package's history.
